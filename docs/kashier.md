# تفعيل كاشير (Kashier)

الكود جاهز. أول ما كاشير يفعّل الحساب، دي الخطوات بالترتيب.

## ١. التجربة بمفاتيح الوضع التجريبي (من غير ما المشترين يشوفوا حاجة)

1. في لوحة كاشير شغّل **Test Mode**، وبعدين من **Integrate now / API keys** انسخ:
   - Merchant ID (شكله `MID-xxxx-xxx`)
   - Payment API Key
   - Secret Key (لازم يكون ليه صلاحية الاسترداد Refund)
2. في Vercel → المشروع → Settings → Environment Variables (Production) حط:
   - `KASHIER_MERCHANT_ID`
   - `KASHIER_API_KEY`
   - `KASHIER_SECRET_KEY`
   - `KASHIER_MODE` = `test`
   - **سيب** `PAYMENT_PROVIDER` = `manual` زي ما هو.
3. اعمل Redeploy.
4. ادخل لوحة الأدمن → **بوابة الدفع**: لازم تشوف ✅ قدام الثلاث مفاتيح، واضغط **اختبر الاتصال بكاشير**.
5. اشتري منتج رخيص من متجرك وانت داخل بحساب الأدمن: في صفحة الدفع هتلاقي زرار كاشير زيادة (المشترين مش بيشوفوه).
   ادفع بكارت الاختبار من صفحة كاشير (أرقام كروت الاختبار موجودة في توثيق كاشير). لازم الطلب يبقى "مدفوع" والكود يتسلم.
6. جرّب الاسترداد: لوحة الأدمن → الطلبات → **رجّع الفلوس عبر كاشير** على نفس الطلب. لازم يظهر رقم عملية الاسترداد، والعملية تظهر Refunded في لوحة كاشير.

## ٢. التشغيل الحقيقي

1. في لوحة كاشير اقفل Test Mode وانسخ مفاتيح **Live** (بتختلف عن مفاتيح التجربة).
2. في Vercel غيّر:
   - `KASHIER_API_KEY` و `KASHIER_SECRET_KEY` للمفاتيح الحقيقية
   - `KASHIER_MODE` = `live`
   - `PAYMENT_PROVIDER` = `kashier`
3. Redeploy، وبعدين **اختبر الاتصال بكاشير** من صفحة بوابة الدفع.

## التحويل اليدوي كاختيار احتياطي

طول ما `MANUAL_INSTAPAY` أو `MANUAL_WALLET` موجودين في Vercel، المشتري بيشوف زرارين:
"ادفع بالكارت أو المحفظة" (كاشير) و"تحويل إنستاباي أو محفظة" (يدوي زي دلوقتي).
عايز كاشير بس؟ امسح الاتنين. عايز ترجع للتحويل اليدوي بالكامل؟ رجّع `PAYMENT_PROVIDER` = `manual`،
والطلبات اللي كانت بدأت على كاشير هتتأكد عادي طول ما المفاتيح موجودة.

## الاسترداد

- **التاجر عمل استرداد** أو **الأدمن قبل شكوى باسترداد** على طلب مدفوع بكاشير: الطلب بيظهر في "مرتجعات للتحويل"،
  ومعاه زرار **رجّع الفلوس عبر كاشير** اللي بيرجّع المبلغ كله لكارت/محفظة المشتري.
- **من صفحة الطلبات** على طلب مدفوع بكاشير: الزرار بيخصم البيع من التاجر ويرجّع الفلوس في خطوة واحدة.
- لو رجّعت الفلوس من لوحة كاشير نفسها، اضغط "حوّلت الفلوس للمشتري" عشان يتسجل.
- لو ظهرت رسالة "مقدرناش نوصل لكاشير"، افتح لوحة كاشير الأول واتأكد إن الاسترداد ما اتعملش قبل ما تجرب تاني.

## الأمان

- الطلب مش بيتعلم "مدفوع" من رسالة الـ webhook ولا من رابط الرجوع، لكن بعد ما السيرفر يسأل كاشير بنفسه بالـ Secret Key ويلاقي العملية CAPTURED.
- الـ webhook (`/api/payments/kashier/webhook`) والرجوع بيتحقق من توقيعهم بالـ Payment API Key (HMAC-SHA256).
- رابط الـ webhook بيتبعت لكاشير مع كل عملية، فمش لازم تسجله في اللوحة.
